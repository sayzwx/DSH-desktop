# DSH Desktop v0.3.0 — 原生插件市场

## 🆕 原生插件市场（桌面端内置，不再跳转 Web UI）

- 左侧边栏新增「🛒 插件市场」入口，打开**桌面端原生的市场页面**，完全贴合星空主题，不跳转浏览器。
- 四个标签页与 Web 端市场同构：**发现 / 已安装 / 主题 / 备份与恢复**。
- **发现**：搜索 + 全部分类筛选 + 卡片网格（名称 / 作者 / ⭐ 星级 / 下载量 / 描述），一键安装社区插件（驱动市场数据源 awesomesh 1691+ 款插件）。
- **已安装**：启用 / 停用开关、一键更新、全部更新、卸载；展示加载状态（已加载 / 重启后生效 / 异常 / 已停用 / 普通依赖…）。
- **主题**：社区主题安装 + 启用 / 停用（同一时间仅一款主题生效）。
- **备份与恢复**：本地文件导出 / 导入预览恢复；WebDAV 备份 / 恢复；GitHub Gist 备份 / 恢复。
- 安装 / 更新 / 卸载带实时进度条，可取消；需要重启的变更显示「重启桌面端」横幅（安全重启应用）；被 pnpm 拦截的构建脚本可一键「允许构建并重试」。

## ✨ 桌面端体验修复（承接）

- **工具权限审批可视化**：approval/requested 现在以桌面端可见卡片呈现（🔐 允许一次 / 拒绝），不再只能去 Web 界面处理。
- **修复确认弹窗文案**：不再把删除弹窗的「确认删除」错误复用到全权限切换等风险确认上（按操作语义显示正确按钮文案）。

## 🔧 其他

- 内置 **dshmarket 1.14.1**（设置 → 插件市场可选；桌面端以原生页面呈现同一套市场数据）。
- 适配引擎 **dsh-v0.1.0-rc.8**（官方最新发行版）。

## 下载

- `DSH-Desktop-v0.3.0-Setup.exe`：自解压安装器（引擎按需自动获取并构建，国内加速镜像优先）。
- `DSH-Desktop-v0.3.0.zip`：便携版（解压后运行 setup.bat 或在 app 目录直接启动）。
