            🛰
            关于观测站
            ▾
          

          

            

              
DeepSeek Harness (dsh) 是 DeepSeek 的开源 agent harness，一切皆插件，由 Cordis 驱动。

              
本观测站通过 Electron 封装：一键启停 pnpm dsh web、实时日志、结果浏览、动态星空主题。

              
Harness 引擎:点击「启动 Harness」自动探测本机已有的官方引擎(npm 全局、npx 缓存或 %LOCALAPPDATA%\DSH\harness 源码目录),没有则自动获取;也可用环境变量 DSH_HARNESS_DIR / DSH_NODE_EXE 显式指定。
