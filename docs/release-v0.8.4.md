# DSH Desktop v0.8.4 发布说明

补丁版：修 v0.8.3 里「更新后插件市场加载不出来」的问题。
基线 v0.8.3 → v0.8.4。产物：`dist/DSH-Desktop-v0.8.4-Setup.exe`、`dist/DSH-Desktop-v0.8.4.zip`。

## 修的是什么

**症状**：从旧版本更新到 v0.8.3 后，打开「插件市场」只看到
「插件市场服务未就绪 · 请先启动 Harness 引擎」，插件列表一直出不来。

**排查结论**（真机复现 + 页面自证日志）：

- 市场后端**完全正常** —— `marketCheck` 返回 `{ready:true, loaded:true, installed:true, v1.18.0}`，
  `/dsh-market/status` 也返回正常 JSON，201 个插件能正常拉到。
- 真因是**时序 + 文案 + 不自动恢复**三件事叠在一起：
  更新之后必然重启引擎，而引擎**冷启动要几十秒**；用户在这个窗口里打开市场页，
  页面探测到引擎状态是 `starting` 就判定「未就绪」，
  文案却写成**误导性**的「请先启动 Harness 引擎」（其实正在启动）；
  更关键的是引擎随后就绪后，页面**不会自己回来** —— `boot()` 只在点击左侧导航时执行一次，
  用户必须自己找到页面角落里那个「重试」才会恢复。

**修复**：

1. **区分「正在启动」与「没启动」**：`starting` / `installing` 时显示
   「Harness 引擎正在启动…（首次或刚更新后会慢一些，就绪后本页会自动加载）」。
2. **自动重试**：未就绪时每 2 秒自探一次，**就绪即自动进入**，不用点任何按钮；
   最长等 120 秒，期间显示已等待秒数，超时给出下一步提示。
3. **需要人工动作时不空转**：要重启桌面端、或「装了但引擎没加载」这类情况不自动重试
   （避免用户对着转圈等一个不会自己好的状态）。
4. 就绪后停止轮询再加载，避免后台空跑。

## 升级建议

- 已经在 v0.8.3 上的用户：**升级到 v0.8.4** 即可，市场页会在引擎就绪后自己加载出来。
- 如果暂时不升级，v0.8.3 上的临时办法：等引擎就绪（约 30–60 秒）后点市场页里的
  **「重试」**，或重启一次 DSH Desktop 再打开市场。

## 安装

- 覆盖安装 `DSH-Desktop-v0.8.4-Setup.exe`；应用内「检查更新」也可直接升级。
- 国内加速：官方链接前加镜像前缀，例如
  `https://ghfast.top/https://github.com/sayzwx/DSH-desktop/releases/download/v0.8.4/DSH-Desktop-v0.8.4-Setup.exe`
