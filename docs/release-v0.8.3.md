# DSH Desktop v0.8.3 发布说明

基线 v0.8.2 → v0.8.3。产物：`dist/DSH-Desktop-v0.8.3-Setup.exe`（Inno 一键安装）、
`dist/DSH-Desktop-v0.8.3.zip`。本版是**观感与工程能力**的一轮大改：对话区重排、
右侧从浮层变成真正的一列、产物变成卡片、内置 Git 集成、主题扫描可诊断。

---

## 一、内置 Git 集成（新）

- 输入框下方一条状态栏：`仓库名 | 本地 | ⎇ 分支 ▾`，右侧显示 `● N 处改动 ↑1 ↓2`。
- 点分支弹出面板：搜索 + 本地分支列表（当前勾选）+ **新建分支**（从当前 HEAD 切出）；
  不是仓库时给「初始化仓库（main）」；没装 Git 时明确写「未检测到 Git」。
- **跟着当前会话走**：切会话时状态栏会换到那条会话的真实运行目录（原先只在切工作区时刷新）。
- 安全：全程 `spawn(git, [参数数组])` 不拼 shell；目录走白名单（存在 + 目录 + 在允许根下）；
  分支名白名单挡 `-b` / `--help` / `../etc` 这类参数注入；`git diff` 只允许仓库内相对路径。

## 二、侧边预览（新，替代原先的右下角浮层）

- 工具条上一个**右侧面板图标**（有按下态）开合一列，列为**布局内的一列**（与左侧会话列表同一套
  面板语言），不再压在壁纸上。
- 五个动作：打开工作区文件（Alt+E）／打开侧边任务／**内置浏览器**（Ctrl+T）／**审阅**（Ctrl+Shift+G）／
  打开终端（Ctrl+Shift+J）。
- **内置浏览器是真内嵌**：用 `WebContentsView`（独立 webContents，不受页面 CSP 限制）——
  iframe 方案打不开外部站点。地址栏只放行 http/https/file，弹窗与外链交系统浏览器，权限一律拒绝。
- **审阅**：git 改动清单 + 单文件 diff（只读、+/- 着色）。

## 三、对话区观感重做

- 助手回答**不再套气泡**（正文直接排版，铺满 960px 列）；用户消息是右侧圆角气泡。
- 字号层级：正文 13 → **14.5px**；代码块 10.5 → **12.5px**（语言条 + 复制按钮）；
  消息间距 12 → 22px；表格/引用/行内代码各有样式；思考块改成克制的小芯片。
- **新增角色行**（头像点 + DeepSeek + 时间）—— 此前消息没有任何身份标记。

## 四、产物变成卡片

每份产物是卡片：**类型图标**（11 类配色）+ 文件名 + **体积 · 时间** + 悬停操作
（在文件夹中显示 / 复制路径），右键菜单：打开 / 在文件夹中显示 / 复制路径 / **添加到对话框**。
产物多时列表内滚动（不再截成"6 个 +N"）。为此新增两个主进程能力：`host:showInFolder`、`files:stat`。

## 五、会话与工作区归属（修一个真 bug）

- 🔴 **「未分组」里打开工作区，打开的是引擎目录（harness 源码）**。根因：引擎 `session.list`
  本来就带每条会话的真实 `cwd`，而桌面端把它丢了 → 只能回落到默认目录。
  现在 `chat:list` 带出 `cwd`，列表**每条会话下方直接显示真实运行目录**（落在引擎目录的标 ⚠）。
- 「未分组」正名为「**未归入工作区**」（它确实是"没有归属"，不是显示分组）：悬停有解释，
  右键新增「归入工作区…」/「用这条会话的目录新建工作区」——历史遗留会话可一键归位。
- **新建会话不再产生孤儿**：当前筛选的工作区 → 上次用过的工作区 → 一个都没有就引导选目录建工作区
  （不再拿引擎目录凑合）。
- Git 状态栏 / 打开工作区文件 / 审阅 / 终端都作用在**当前会话的真实目录**上。

## 六、主题迁移

- **扫描根扩到**：所有 `profiles/*/node_modules`、`~/.dsh/node_modules`、harness 目录及其同级、
  以及**手动添加的目录**；`DSH_HOME` 支持环境变量（此前硬编码 `~/.dsh`）。
- **扫描目录逐个显示状态**：`✓ 6 个包` / `⚠ 读不到：EPERM` / `○ 不存在`，并提供
  **「＋ 添加扫描目录」**（原生目录选择器，选到上层会自动进 `node_modules`）。
  「主题扫不出来」这类问题从此可以**当场定位**。
- **精修对比度护栏**：模型改了底色却没给文字色（深底深字 / 浅底浅字）会被自动修正 ——
  只动前景色、保持色相、按"文字实际压在哪儿"分级（面板上正文 4.5:1、次要 3:1），
  修正明细如实列在结果里，不偷偷改。
- 主题包识别支持六种形态（含 Cordis 的 `bundle/client.js`、纯 CSS 文件型、`.tczp` 预设型）。

## 七、真机测试基建（新增）

新增 `scripts/app-live-audit.cjs` 与 `scripts/live-ui-check.cjs`：**直接启动已安装的应用**，
用 CDP 驱动它跑真 git 全链路、逐主题对比度、界面几何与产物卡片校验。
本轮的多个真 bug 就是它抓出来的（扫描根只认一个 profile、切会话不换目录、
`git rev-parse` 在 Windows 给正斜杠导致审阅读不到文件）。

## 安装

- **全新安装**：下载 `DSH-Desktop-v0.8.3-Setup.exe` 覆盖安装（引擎不打包进安装包，
  由安装器自动从官方源获取并构建）。
- **从 v0.8.0 / v0.8.1 / v0.8.2 升级**：应用内「检查更新」直接升级；也可到 Releases 页手动下载覆盖安装。
- 国内加速：官方链接前加镜像前缀，例如
  `https://ghfast.top/https://github.com/sayzwx/DSH-desktop/releases/download/v0.8.3/DSH-Desktop-v0.8.3-Setup.exe`

## 已知边界

- **应用内终端**尚未内置（需要 `node-pty` 原生依赖）：当前「打开终端」是在工作区目录开**系统终端**。
- 内置浏览器是"只读浏览"：下载、权限申请（摄像头等）一律不放行。
- 未识别的约 10% 主题包以 patch-only / 运行时拼 CSS 为主，需要逐包适配。
- 「模型全文承接」依赖你自备的模型路由，会产生模型费用，由用户逐个主题自行决定。
