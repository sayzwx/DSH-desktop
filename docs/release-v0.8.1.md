# DSH Desktop v0.8.1 发布说明

基线 v0.8.0 → v0.8.1。分支 `feat/p0-p1-p2-completion`。产物：
`dist/DSH-Desktop-v0.8.1-Setup.exe`（Inno 一键安装）、`dist/DSH-Desktop-v0.8.1.zip`。

本版是**一轮界面缺陷修复 + 主题迁移能力补完 + 新图标**。

## 一、启动行为：自动拉起引擎，且不再自动弹浏览器

- **启动应用即自动拉起 Harness**：以前要手动点「启动 Harness」，现在打开就用。
  （可用 `DSH_NO_AUTOSTART=1` 跳过；控制台仍保留手动启动/停止。）
- **静默启动（本版重要修正）**：启动应用后会**弹出系统浏览器**打开 WebUI —— 根因不在桌面端，
  而是**引擎自己**干的：引擎的 web 应用 `openBrowser` 默认 `true`，`:3080` 就绪后自己打开默认
  浏览器（会打一行 `dsh web: opening the default browser`）。桌面端启动引擎时现在会带
  `--no-open`，**并先探测引擎是否支持该开关再传** —— 老引擎会因未知参数直接退出，
  不能把「少弹一个窗口」变成「引擎起不来」。
- 控制台新增**「打开 Web 端」**按钮（随运行态启停），需要 WebUI 时按需打开。

## 二、插件市场

- **可跳转到项目网页**：每张卡（发现 / 主题）新增「项目网页 ↗ / GitHub ↗」，走系统浏览器打开。
- **筛选与排序**：新增快捷筛选（全部 / 已安装 / 可更新）与排序（默认 / 最多下载 / 最多 Star /
  名称 A→Z），搜索范围扩到分类名。
- **已安装列表补描述**、发现卡描述不再 3 行截断（此前长描述被截断看不全）。
- **变更后联动刷新**：安装 / 卸载 / 启停插件后，主题下拉、主题工作室、主题卡片状态三处立即同步；
  以前卸载插件后应用端不会跟着变。

## 三、桌面端主题迁移：覆盖到「官方皮肤生态」

市场里的主题是**两种格式**，此前只支持一种：

- **token 型**（如 `dsh-neo-skin`）：`client.js` 内嵌 `--dsw-alias-*` 变量表 → 免费确定性迁移。
- **skin 型**（官方皮肤生态，数量很多）：`skin.json` + `bodyAttr` + 一整段 WebUI 专属 CSS，
  **不含 `--dsw-*`** —— 被旧扫描误判成「纯功能插件」，用户装了也搜不到、迁不了。已修：
  - 扫描器认得 `skin.json`（一个包 = 一个方案，浅/深两档），界面标出「skin 型」徽标并显示
    皮肤自带的浅/深**预览图**。
  - **免费路径**承接强调色与命名（底色沿用官方档）。
  - **新增「模型全文承接」**（付费、由用户逐个决定）：整包 26 万字符不可能直接喂模型，
    先压成约 3 万字节**结构摘要**（配色分布 / 形状语言 / 资源表 / 代表性规则样本），
    再让模型用**桌面端真实存在的类名与变量**重新表达 —— 关键点是**皮肤自带的图片能真的搬过去**：
    图片走 `skinAssetUrl("<hash>.<ext>")` → 包内 `assets/runtime/`，只有**主题包目录内**的
    图片/字体被放行（越界、远程、`data:`、非白名单类型一律拒并说明原因）。
- 市场主题卡新增**「迁移到桌面端」**一键链路：未安装会先自动安装（引擎热加载），
  再免费迁移全部档位并直接应用。

## 四、界面与主题缺陷修复

- **浅色主题对比度系统性修复**（用户反馈「好多地方还是白的，都融入背景里了」）：
  - 根因：浅色下卡片底色是 `rgba(255,255,255,0.88)`（纯白）压在白页面上、边框只有 10% 黑
    ——「白卡压白底」。已改为官方浅色档的卡片灰 `#f5f6f7`，并建立
    页面 `#fff` < 卡片 `#f5f6f7` < 浮层 `#eceef1` 的三级层次。
  - 仪表盘图表的文字颜色**硬编码了深空主题的色板**（近白文字），浅色下等于白字压白卡。
    改为从当前主题的 CSS 变量取色，并在切主题时重绘（canvas 是像素，不重绘就留着旧颜色）。
  - 主按钮/危险按钮原是「半透明色底 + 同色系文字」的发光风格（为深色底设计），
    浅色下实测只有约 2.4:1。浅色下改为实底 + 白字。
  - 浅色下的**弹窗遮罩**原用近白色做遮罩（白上叠白），已改为真正的暗化。
  - 侧栏（64px 宽）底部状态文字与「打开 Web UI」按钮长文案被裁成残块，已改为指示灯 + 短标签，
    完整文案进 tooltip。
- **窗口边框跟随主题**：切主题时同步引擎的配色倾向，Windows 标题栏不再独立于主题。

## 五、新图标

应用图标换成鲸鱼造型（去掉了生成器水印），多尺寸 `.ico`（16~256），
窗口、托盘、安装器、快捷方式全部生效。

## 安装

- **全新安装**：下载 `DSH-Desktop-v0.8.1-Setup.exe` 覆盖安装即可（引擎不打包进安装包，
  由安装器自动从官方源获取并构建）。
- **从 v0.8.0 升级**：应用内「检查更新」直接升级（v0.8.0 起更新器已修复）。
  若下载异常，到 Releases 页手动下载 `.exe` 覆盖安装。
- 国内加速：在官方链接前加镜像前缀，例如
  `https://ghfast.top/https://github.com/sayzwx/DSH-desktop/releases/download/v0.8.1/DSH-Desktop-v0.8.1-Setup.exe`

## 已知边界

- 「模型全文承接」依赖你自备的模型路由，会产生模型费用，**由用户在界面上逐个主题自行决定**；
  桌面端类名是硬约束（模型写出清单外的类名会被丢弃），目标是「同色系同性格的简洁版」，
  不是逐像素等同原皮肤；整段皮肤 CSS 也不会被逐条翻译。
- 迁移后的主题可随时在「设置 → 星域主题」切换，也可在主题工作室里移除（不影响 WebUI 插件本身）。
