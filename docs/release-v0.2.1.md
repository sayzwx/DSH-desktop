## v0.2.1

对话界面向 webUI 看齐 + 多项体验优化：

- **Markdown 排版**：助手回答支持标题 / 粗体 / 斜体 / 行内代码 / 代码块 / 列表 / 表格 / 链接 / 引用 / 分隔线（流式打字纯文本 → 完成一键排版）
- **工具调用卡片化**：按 callId 配对的折叠卡片（🔧 名称 ✓ 完成，含可展开输出与 exit code），修复此前 call/result 重复堆叠、无名乱序问题
- **模型编辑面板（webUI 同款）**：已启用提供商卡片也有「编辑提供商配置 / 删除提供商」；面板含 API 密钥（改 key + 测试连接）与可折叠「自定义设置」（API 协议从 schema 动态枚举、API 地址默认/自定义、模型目录添加/获取/删除模型）
- **工具栏精简**：推理强度、权限预设、发送模式（排队/插话）改为紧凑下拉选择框
- **模型面板状态提示**：未开会话/加载中/加载失败显示真实原因，不再误报“未连接 harness”
- **一键安装 / 引擎自动获取**：环境预检 + Node 缺失时优先 winget 安装最新 LTS
- **隐私修复**：安装包使用纯净默认配置，不含开发者任何个人配置/密钥

## 安装

- **Setup.exe**：双击自解压安装（推荐）
- **zip**：解压后运行 `setup.bat`（需本机已装 7-Zip 时可选生成 Setup.exe）

引擎在首次启动时自动拉取（含 Node 环境预检），无需手动准备。
