## v0.5.0

### ⌨️ 斜杠命令面板重做（对齐 webUI，核心修复）
- 输入 `/` 后 **`/` 保留在输入框里**（不再被吃掉），命令 / 技能选择框在输入框**上方**弹出。
- **点击选项即可执行**——此前点击完全无效的缺陷已修复；↑↓ 选择 · Enter 执行 · Tab 补全 · Esc 关闭。
- 选择框**可上下滚动**，删除 `/` 选择框随之消失。

### 🔄 后台常驻服务（关闭窗口不断线）
- 关闭窗口只**隐藏到托盘**，Harness 服务继续在后台运行，会话不中断。
- 再次打开应用 / 双击快捷方式 → 自动唤回窗口并接管 `:3080`。
- 新增系统托盘菜单：显示主窗口 / 启停 Harness / 退出。
- 设置页新增「后台与退出」：隐藏到托盘 · 停止 Harness 并退出 · 仅退出应用（保留服务）。

### 🪟 窗口自动检测
- 桌面端实时监控本应用创建的所有窗口（含辅助/弹窗），侧边栏「窗口」指示器显示数量与标题。
- 任何新窗口开闭、隐藏都能看到——彻底告别“开了窗口却看不见、以为卡住”的情况。

### 🛍 插件市场开箱即连
- 市场未就绪时可直接**「启动 Harness」一键拉起并自动重连**。
- 安装器内置 `dshmarket` 插件 + 应用内自动补装，装完即用。

### 📦 真正的安装器（Inno Setup）
- Release 里的 `Setup.exe` 是**标准 Windows 安装向导**（不是自解压压缩包）。
- **可选择安装目录**：app / harness / tools 全部随所选目录布局，**自动适配用户选择的路径，绝不绑定开发者本机路径**。
- 向导内置**环境预检页**：进入即检测 Node / 网络 / 磁盘，缺失项明确列出，随后在你选择的目录内自动补齐并拉取引擎。

### ⚡ 更新即正规软件升级
- 一键更新下载到「应用安装根目录\updates」（不再落账户/临时路径）。
- 新版 Setup.exe **静默覆盖安装到原安装目录**（替换旧版，不另建新文件夹）。
- 重建桌面快捷方式指向新版，完成后**自动重启进新版**。
- 下载继续走国内加速镜像（ghfast.top / ghproxy.net / gh-proxy.com / gh.ddlc.top）。

### 🎨 界面质感升级
- 更精致的标题字距与渐变、卡片玻璃层次、按钮高亮描边与按压反馈、聚焦光晕、主题化滚动条、选中文字配色。

## 安装

- **Setup.exe（推荐）**：双击，选择安装目录，向导自动预检环境、装完自动启动。
- **zip**：解压后运行 `setup.bat`。

> 手动下载加速：官方链接前加镜像前缀，如 `https://ghfast.top/https://github.com/sayzwx/DSH-desktop/releases/download/v0.5.0/DSH-Desktop-v0.5.0-Setup.exe`
